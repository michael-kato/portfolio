Work Experience

2014 - 2023

Most of my professional work is behind NDAs or lived inside internal pipelines, so here is a breakdown of what I actually worked on at Meta, Apple, and Sledgehammer Games.

Sep 2020 - Sep 2023

Meta Reality Labs

Horizon Worlds (VR)

Senior Technical Artist (IC5)

  • 300k MAU
  • Unity · C#
  • SQL · Perfetto

My main role at Meta Reality Labs was looking at performance as a problem holistically while embedded with a performance engineering team. That meant deep dives with RenderDoc, Unity Profiler, and Perfetto, direct C# fixes, instrumentation, automated performance testing, emergency triage, education initiatives, cross-functional outreach, and a lot of one-off debugging tasks.

Code Contributions

I contributed directly to the Horizon Worlds Unity C# codebase with performance fixes and instrumentation. I tracked down and patched dozens of wasteful memory allocations that were causing garbage collection spikes and memory fragmentation (which often led to OOM crashes on Quest).

I also swept through hundreds of C# files to batch or cache Unity native calls and clean up wasteful work in avatars, particles, navigation portals, collision, and game script. Whenever a ship-blocking regression showed up, I handled it full cycle: profiling, narrowing down the likely culprit with internal tools, and either reverting, disabling, or rate-limiting the change or working with the owner to fix it.

Performance Automation Framework

I worked with lead engineers to build a performance monitoring system for Horizon Worlds' weekly release cadence. It started as a solo initiative and eventually grew into a dedicated team effort.

We instrumented most of the game code with a custom C# profiling system that ran everywhere: pre-submission, continuous integration, on-demand developer tests, and live user builds. It tracked physics, scripting, animation, rendering, VFX, audio, and garbage collection, ran per-commit A/B comparisons against benchmarks, and caught regressions within hours along with downloadable profiler artifacts for debugging.

SQL Dashboards & Telemetry

Horizon Worlds collected a huge amount of data from automation, developer testing, and live users, and when I first started much of it wasn't being surfaced anywhere. I built a bunch of SQL dashboards so anyone on the team could actually see performance trends.

People could slice data by world, player count, hardware SKU, game version, or time of day. I set up separate dashboards for automation runs, general perf queries, and specialized "hitch" (CPU bubble) trackers, plus automated email alerts when a regression popped up. It made it much easier for teams to prioritize optimization work and prove whether a fix actually helped.

Apr 2019 - Aug 2020

Apple Contract

Apple Vision Pro (Synthetic Data)

Technical Artist

  • Python · Maya
  • AWS · Perforce
  • Deadline Farm

At Apple I built pipeline features and tools for a fast-moving synthetic data team that rendered photoreal video of everyday environments to help train the Apple Vision Pro headset tracking system.

Outsourcing Pipeline

To support a high-volume outsourcing operation, I built an automated pipeline for both sending our tools out to vendors and bringing completed assets back into our Perforce depot.

On the delivery side it packaged up all Python dependencies in-place, bundled metadata file references, zipped the environment, pushed it to AWS, and emailed confirmation to the vendor. On ingestion it pulled finished assets into Perforce, ran our QA checks automatically, and pinged artists when new assets were ready for manual review, cutting out a lot of manual handoff errors.

Asset Validation QA Tools

We were processing thousands of 3D models from both internal teams and external vendors, and asset quality issues kept causing pipeline failures that wasted render farm time and artist hours.

Together with the TA team, we built Python validation tools in Maya that checked for common import problems like abnormal scale, missing textures, and bad material settings. It also generated thumbnail images automatically for the asset browser and automated LOD prep across Maya scenes so things stayed consistent.

Procedural Scene Generation

Apple Vision Pro needed huge amounts of photoreal imagery for visual recognition training. Working with a lead TA, I built a procedural system that generated semi-randomized interior layouts overnight without needing more artists to build rooms by hand.

It took existing interior scenes, modified the floorplan by dynamically extruding new walls, windows, and crevices, and rearranged furniture and props into new layouts. Then it submitted the new scenes to Perforce, kicked off Deadline renders, and emailed stakeholders when jobs went out.

Jan 2014 - May 2019

Sledgehammer Games

Call of Duty: WWII, AW, Cold War

QA → Assoc. TA → Technical Artist

  • 60 fps Console
  • Python · MEL · C++
  • 300+ Devs Supported

I started at Sledgehammer in QA, moved into a VFX technical artist role building destructible and dynamic props (integrating VFX, audio, physics, collision, rigging, and scripting across hundreds of props), and eventually shifted over to focus on performance optimization, tools, and pipeline work supporting over 300 developers.

Performance Ownership

For Call of Duty: WWII, I was the main performance stakeholder keeping 60fps across the singleplayer campaign, zombies mode, hub world, and several multiplayer maps on console.

I ran weekly perf reviews with art and design leads across environment, lighting, VFX, and design, and learned enough of each team's toolchain to either fix issues myself or give specific recommendations. Common fixes were adding occluders, dialing back VFX physics, reducing dynamic light counts and radii, adding LODs, culling character bones, or tweaking rendering flags in game script. I also caught a cross-studio team falling behind on their level early enough to escalate to production and get help in place before ship.

LOD Generation Pipeline

I partnered with Activision's central technology group to integrate a proprietary LOD generation algorithm into Sledgehammer's asset pipeline, replacing hand-authored LODs across nearly every environment prop, vehicle, character, and weapon in Call of Duty: WWII.

We set up presets tuned for hard surface, organic, and foliage meshes, and it worked well enough that I was able to add and tune LODs for most of a full Call of Duty title pretty much on my own. I also extended it into a Maya tool that atlased textures for ultra-cheap final LODs, combining decimation, custom skinning tools, and Python automation.

Edge Cleanup Tool (Maya)

I wrote a Maya tool that inspects mesh topology to find redundant edges that can be deleted and unnecessary hard edges that can be softened to bring vertex counts down. Neither operation changes the silhouette much, and both can cut out a lot of wasted geo complexity.

It uses adjustable angle thresholds, checks UV seams so it won't delete edges that break UVs, and includes a greedy triangulation pass that helps assets hold their shape better during decimation. It became a regular step in our export process, and the normal softening pass alone saved us a full millisecond in some environments.
