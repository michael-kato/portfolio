Unity C# Codebase Optimization

  • Patched dozens of wasteful memory allocations across the codebase, cutting GC spikes and fragmentation that triggered OOM crashes on Quest.
  • Swept hundreds of C# files to batch/cache native Unity calls and optimize avatars, particle systems, navigation portals, collision, and game script.

Automated Performance Framework

  • Co-designed a C# profiling and automated testing system for Horizon Worlds' weekly release cadence, starting as a solo initiative before growing into a dedicated team effort.
  • Tracked physics, scripting, animation, rendering, VFX, audio, and garbage collection across pre-submit, CI, developer tests, and live production builds.
  • Ran per-commit A/B benchmark comparisons and surfaced downloadable profiler artifacts within hours of a regression.

SQL Telemetry & Hitch Dashboards

  • Surfaced previously buried automation, test, and live-user telemetry into SQL dashboards aggregated by world, player count, hardware SKU, build version, and time of day.
  • Built specialized CPU hitch ("bubble") trackers and automated email regression alerts to stakeholders.
  • Enabled engineering and leadership to prioritize optimizations using live data rather than guesswork.
Apr 2019 - Aug 2020

Apple Contract

Apple Vision Pro · Synthetic Data

Technical Artist

  • Python · Maya
  • AWS · Perforce
  • Deadline Farm

Built Python pipeline automation supporting a high-volume synthetic data operation that rendered photorealistic interior environments to train Apple Vision Pro's computer-vision tracking models.

End-to-End Outsourcing Pipeline

  • Automated outbound vendor delivery: packaged Python dependencies in-place, bundled metadata references, zipped environments, pushed to AWS, and emailed confirmations.
  • Automated inbound ingestion: pulled completed assets into Perforce, ran the full QA validation suite, and notified artists for manual sign-off.
  • Eliminated manual handoffs on both ends so broken environments never polluted ML training jobs.

Asset Validation & Thumbnail QA

  • Processed thousands of 3D models from internal teams and external vendors with automated checks for scale anomalies, missing textures, and bad material configurations.
  • Generated asset-browser thumbnails and automated LOD steps across Maya scenes in Python.
  • Caught upstream failures before expensive farm renders ran.

Procedural Interior Scene Generation

  • Built a procedural layout generator with a lead TA to synthesize new photoreal interior training data overnight without additional artist headcount.
  • Dynamically modified floorplans (extruding walls, windows, and crevices) and randomized furniture/prop arrangements.
  • Auto-submitted scenes to Perforce, dispatched Deadline render jobs, and emailed stakeholder reports.
Jan 2014 - May 2019

Sledgehammer Games

Call of Duty: WWII · AW · Cold War

QA → Assoc. TA → Technical Artist

  • 60 fps Console
  • Python · MEL · C++
  • 300+ Devs Supported

Started in QA, moved into VFX destructibles (shipping hundreds of physics, rigged, and scripted props), and became the primary performance stakeholder and pipeline tools TA for Call of Duty: WWII, holding 60fps across consoles and automating LODs game-wide.

Game-Wide 60fps Performance Ownership

  • Primary performance stakeholder across singleplayer campaign, zombies, hub world, and multiplayer maps on console.
  • Ran weekly reviews across environment, lighting, VFX, and design, diagnosing and fixing occluders, dynamic lights, physics VFX, bone culling, LODs, and game script.
  • Identified and escalated a cross-studio team falling behind performance targets early enough to close the gap before ship.

Automated LOD Generation Pipeline

  • Partnered with central technology to integrate a proprietary LOD algorithm into Sledgehammer's pipeline, replacing hand-authored LODs for nearly every prop, vehicle, weapon, and character in Call of Duty: WWII.
  • Tuned geometry presets for hard surface, organic, and foliage assets so one TA could tune LODs for almost an entire Call of Duty title.
  • Extended into a Maya tool atlasing textures for ultra-cheap final LODs, combining decimation, skinning, and Python automation.

Maya Edge Cleanup & Triangulation Tool

  • Analyzed mesh topology to strip redundant coplanar edges and soften unnecessary hard edges that split vertex normals, while preserving UV seams and silhouettes.
  • Implemented greedy triangulation so meshes retained clean silhouettes through downstream decimation.
  • Adopted into the standard asset export process; normal softening alone saved a full millisecond in some environments.
